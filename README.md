# 🎨 VelvetCanvas

VelvetCanvas is a modern desktop canvas application built with **Python** and **PySide6**.

It provides a simple and creative workspace for designing compositions using **text and images**. Users can add items to the canvas, move them freely, resize them, rotate them, control their layering, customize text, save projects, and export finished designs.

VelvetCanvas is designed as a lightweight visual composition tool with a clean desktop interface.

---

## ✨ Features

### 📝 Text Tools

- Add text to the canvas
- Drag and reposition text freely
- Resize text areas
- Double-click text to edit
- Edit text from the Properties panel
- Select different fonts
- Change font size
- Bold text
- Italic text
- Change text colour
- Rotate text
- Automatic word wrapping
- Add quick romantic text presets
- Add emoji and decorative text

---

### 🖼 Image Tools

- Add PNG images
- Add JPG and JPEG images
- Add BMP images
- Add WebP images
- Drag images around the canvas
- Resize images
- Preserve image aspect ratio by default
- Hold **Shift** for free resizing
- Rotate images
- Duplicate images
- Change image layer order

---

### 🎨 Canvas Features

- Large portrait-oriented design canvas
- Custom canvas background colour
- Optional grid display
- Zoom support
- Fit canvas to window
- Smooth image rendering
- Anti-aliased text and graphics
- Selection borders
- Interactive resize handles

---

### 📐 Object Controls

- Select objects
- Move objects
- Resize objects
- Rotate objects
- Duplicate selected objects
- Delete selected objects
- Bring objects forward
- Send objects backward

---

### 💾 Project Management

- Create a new project
- Save projects as JSON
- Open saved projects
- Restore text properties
- Restore item positions
- Restore item sizes
- Restore rotations
- Restore layer ordering
- Restore canvas background colour

---

### 📤 Export

VelvetCanvas can export your finished design as:

- PNG image
- PDF document

Selection borders and resize handles are automatically hidden during export.

---

## 🖥 Application Interface

VelvetCanvas provides:

- Main design canvas

- Properties panel
- File menu
- Text controls

- Canvas controls
- Export tools
